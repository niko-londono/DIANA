# FINANZAS — Financial Budget Dashboard

Aplicación de presupuesto financiero personal construida con React + Vite.

## 🚀 Desarrollo Local

```bash
npm install
npm run dev
```

## 📦 Build

```bash
npm run build
```

## 🌐 Deploy

El deploy a GitHub Pages se realiza automáticamente mediante GitHub Actions al hacer push a la rama `main`.

**URL**: https://niko-londono.github.io/FINANZAS/

## 🛠 Tech Stack

- React 18
- Vite 5
- Vanilla CSS
- localStorage para persistencia
