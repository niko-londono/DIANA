# FINANZAS — Financial Budget Dashboard

Aplicación de presupuesto financiero personal construida con React + Vite.

## 🚀 Desarrollo Local

```bash
npm install
npm run dev
```

## 📦 Build

```bash
npm run build
```

## 🌐 Deploy

El deploy se hace en **Vercel** (proyecto `diana`): cada push a `main` publica producción automáticamente. GitHub Pages ya no se usa.

## 🛠 Tech Stack

- React 18
- Vite 5
- Vanilla CSS
- localStorage para persistencia
