# FINANZAS — Financial Budget Dashboard

Aplicación de presupuesto financiero personal construida con React + Vite.

## 🚀 Desarrollo Local

```bash
npm install
npm run dev
```

## 📦 Build

```bash
npm run build
```

## 🌐 Deploy

El deploy se hace en **Vercel** (proyecto `diana`): cada push a `main` publica producción automáticamente. GitHub Pages ya no se usa.

## 🛠 Tech Stack

- React 18
- Vite 5
- Vanilla CSS
- Google Sheets + Google Apps Script (`Code.gs`) como base de datos en la nube
- localStorage como respaldo local (y almacenamiento de las tarjetas)
